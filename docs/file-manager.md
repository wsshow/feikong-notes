# 文件管理器

从普通笔记首页的文件夹图标进入。文件库独立管理用户导入的资料，支持目录、搜索筛选、收藏、最近打开、预览和回收站。界面规则见[设计规范](../DESIGN.md#文件管理器)。

## 导入与存储

导入复制文件，不移动或修改来源文件。Android 使用 `ACTION_OPEN_DOCUMENT` 取得内容 URI，在原生后台线程以 256 KB 缓冲复制；文件内容不经过 MethodChannel，也不整体载入 Dart 内存。其他平台使用 `file_selector` 和流式写入。显示当前文件、字节数与批次进度，取消中止当前文件并保留已提交的文件；失败的文件可重新选择。

`FileLibraryStore` 在 `notes/files/library/index.json` 保存版本为 1 的逻辑目录树，文件内容存于 `data/<uuid>.<extension>`。用户文件名与实际路径分离，修改名称或移动目录不改写文件内容。所有读写按存储根目录串行化；先完成 `.part` 文件，再原子替换索引。复制文件夹时先准备全部新内容，成功后一次提交索引。重名复制、导入和恢复自动编号；新建和重命名重名时提示错误。路径、名称、父子循环及重复存储引用均需验证。

删除仅在选定的顶层条目记录删除时间，整个子树从普通浏览、收藏及最近打开中隐藏。恢复保持原父目录，父目录不可用时回到根目录。永久删除只接受已在回收站内的条目，并删除其全部后代。回收站不自动过期，计入本地使用空间。

## 预览范围

| 格式 | 行为 |
| --- | --- |
| PDF | `pdfrx` / PDFium 本地渲染、缩放、文本选择、页码及翻页 |
| JPG、PNG、GIF、WebP、BMP 等 | Flutter 图片解码与缩放；实际支持范围取决于系统/Flutter 解码器 |
| MP3、WAV、M4A、AAC、FLAC 等 | 复用 `just_audio`，播放/暂停及进度拖动 |
| MP4、MOV、WebM 等 | 复用 `video_player`，播放/暂停及进度拖动 |
| TXT、代码、JSON、XML、日志、字幕等 | 本地只读可选择文本；识别 UTF-8 与带 BOM 的 UTF-16 |
| Markdown | 复用 `FkMarkdownView`，不自动加载外部图片 |
| CSV / TSV | 文本方式查看，不宣称为工作表排版预览 |
| ZIP（不超过 32 MB） | 只读列出最多 1,000 项，不解压、不执行内容 |
| DOC/DOCX、PPT/PPTX、XLS/XLSX、ODF、其他格式 | `open_filex` 调用系统兼容应用；未安装应用时说明原因 |

文本预览最多读取 1 MB、显示 200,000 字符，较大文件提示使用其他应用。媒体编码不支持、文件损坏或平台缺少插件时，预览页仍提供使用其他应用打开、分享和另存。音视频离开前台时暂停。预览不上传文件，不依赖 Google/Microsoft 在线文档查看服务，也不承诺无系统兼容应用时完整渲染 Office。

外部打开及分享通过带原始名称的临时副本，避免 UUID 文件名影响格式识别与接收方体验；临时副本在后续操作时清理七天前的目录。Android 另存复用系统文档创建通道，用户自行选位置；iOS 通过分享菜单保存，桌面使用系统保存对话框。当前发布验收仍以 Android 手机为准。

## 首页资料卡

纸短情长首页提供五种可滑开的纸张叠卡：手边资料（最近打开或导入的一份文件）、收藏资料（两份收藏，可通过底部弹窗挑选）、图片记录、继续记录、资料分类。全部使用文件库真实数据；空状态提供导入或选择资料入口。布局偏好以稳定枚举名写入 `settings/editorial-material-deck.json`，不自动轮播。

叠卡用 `GestureDetector` 和 `AnimationController` 实现跟手切换与回弹接管。每页使用独立重绘边界，支持大字体、读屏、方向键和减少动画设置。

## 文件引用

- **创建。** 文件库的“记一笔”创建引用。单文件通过 `linkedNoteId` 继续已有普通笔记。关联笔记被删除或转为隐私时，新建普通笔记。多文件聚合为一张新卡片，保留单文件原有的关联；相同批次并发去重。
- **选择。** 编辑器的“引用文件”支持跨目录搜索、多选和批量导入。选择面板展示可用文件，搜索保留勾选，引用按勾选顺序保存。

- **解析。** `fknotes.fileReferences` 保存稳定文件 ID、文件名和大小快照，每张卡片按 ID 去重，最多 1,000 项。卡片显示数量和前三项，展开后按 ID 读取当前名称并打开预览。移动或重命名仍可解析，回收站或缺失来源显示原引用及不可用原因。
- **编辑。** 卡片可长按拖动，使用附件落点提示和边缘滚动。移动与移除可撤销。点击末尾卡片下方的空白区域进入正文，有可用段落时直接放置光标，否则补一个正文段落。
- **数据。** 移除卡片只修改笔记。复制文件获得新 ID，关联关系由原文件持有。文件名参与搜索、分享和 AI 引用元数据，正文朗读使用正文文本。完整备份同时保留引用和文件库。

对应验证：`editorial_material_deck_test.dart` 验证跟手、反向接管、五种布局及空状态、大字体、独立操作和减少动画；`library_file_note_service_test.dart` 验证零副本引用、混合格式聚合、并发去重、隐私隔离和布局持久化；`note_file_references_test.dart` 验证完整列表、跨目录搜索多选、任意格式导入、深色大字体、撤销恢复及手机尺寸视觉基线。

## 备份与验证

完整备份格式升级为 4，保留 2/3 版本恢复能力。快照在文件库写入锁内复制索引及所有引用文件，包括回收站；文件内容、收藏、目录结构、最近打开时间一并保留。临时文件与未提交内容不进入备份。恢复除校验备份哈希，还验证目录图、存储路径及文件长度，且拒绝无索引引用的额外文件。文件库位于既有受管理 `notes/` 目录，随完整恢复进行替换与回滚；恢复早期备份会按完整恢复语义移除备份中不存在的文件库。

对应验证：`file_library_store_test.dart`、`file_manager_page_test.dart`、`backup_service_cloud_boundary_test.dart`、`app_icon_test.dart`，以及 Android Kotlin 编译。真机还需检查不同系统文档提供程序、大文件导入取消、已安装/未安装 Office 应用，以及设备支持的媒体编码。
