# 笔记日历

首页左下角打开全屏月视图，默认定位本地今天。计数按 `updatedAt.toLocal()` 的日期聚合，并按当前普通或隐私空间过滤。数据未变化时复用日期索引。

## 四种视图

| 视图 | 内容和操作 |
| --- | --- |
| 年 | 十二个月小月历，展示每月数量和有笔记的日期。点击月份打开对应月视图 |
| 月 | 按可用高度展开周行，显示公历、农历和笔记数量。点击日期打开底部时间轴 |
| 周 | 按天分组，顶部汇总笔记数和有记录的天数。每天预览最近两条，点击日期或“查看当天全部”进入日视图 |
| 日 | 展示当天全部笔记，按更新时间倒序，显示标题、最多五行摘要、时间、前三个标签和附件数量 |

周、日卡片和月时间轴可直接打开编辑器，返回后刷新同一日期。月时间轴可查看空日期，日视图就地显示空状态。读取失败显示重试。

## 日期与导航

- 底栏顺序为“年、月、主页、周、日”，独立占据安全区域。系统返回先关闭时间轴，再返回主页。
- 左滑前进、右滑后退，步长对应当前视图。内容随手指平移，标题与底栏固定。松手按距离和速度完成翻页或回弹。点击“今天”或切换视图会取消进行中的过渡。
- 四种视图共用本地焦点日期。周一为一周起点，月底和闰日按目标月份截取有效日期。本地日期计算考虑时区与夏令时。
- 小屏和大字号下，月视图可滚动，年视图减少列数。日期选中时保持公历、农历和数量对齐。颜色、触控与徽标样式见[设计规范](../DESIGN.md#日历与日期时间轴)。

## 农历

使用 [lunar 1.7.8](https://pub.dev/packages/lunar/versions/1.7.8) 在设备上换算。农历展示覆盖公历 1900–2100 年，公历浏览范围为 1–9999 年。

月格按农历节日、公历节日、节气、农历月日的顺序显示短标签，完整名称保留在提示与无障碍描述中。字符串缓存最多 512 天，跨午夜或回到前台时更新今天标记并保留浏览位置。

换算用例参考香港天文台的 [2025 年](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2025e.pdf)和 [2026 年](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2026e.pdf)公历农历对照表。
