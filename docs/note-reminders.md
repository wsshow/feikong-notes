# 笔记提醒

## 实现边界

- Android 手机，一条笔记一个单次提醒；不提供重复提醒、桌面悬浮窗或全屏闹钟。
- `Note.reminderAt` 以 UTC 毫秒持久化在 SQLite `notes.reminder_at`。该字段由 v9 迁移引入，旧笔记初始值为空，编辑和备份保留字段。
- 编辑器元数据写入与自动保存共用队列；仓库提交事务后通知原生调度器。设置失败会回退提醒字段，不误报成功。
- 列表只显示未来提醒，并与时间、标签同一行；到期自动隐藏。编辑器中的历史提醒只显示图标与 `HH:mm`，不重复日期和“提醒时间：”前缀；完整日期仍保留在长按提示与无障碍描述中。提醒字段不会在到期时删除，因此历史时间也能随备份保留；显示时间不等于确认系统已送达。
- `NoteReminderService` 只向原生传递数据库路径与笔记 UUID，不缓存通知正文。桌面等未实现平台明确提示不支持。

## Android 调度

`NoteReminderBridge` 使用 `AlarmManager.setExactAndAllowWhileIdle` 和不可变、按 UUID 区分的 `PendingIntent`。清理后台进程不依赖 Flutter 定时器；用户在系统设置中强行停止应用会被 Android 取消调度，需重新打开应用。

首次设置通过系统界面请求 `POST_NOTIFICATIONS` 和 `SCHEDULE_EXACT_ALARM`。未授权时不保存新时间，不使用 `USE_EXACT_ALARM` 绕过特殊访问授权。已保存的提醒在权限被撤销后可能无法送达，重新授权并打开应用后恢复未来调度。

接收器处理闹钟、设备启动、应用更新、时间或时区变化及准时提醒权限恢复。重启与恢复备份只调度未来时间，不补发已过期记录。时区变化保留原先选择的绝对时刻，界面换算为当前本地时间。

普通内容使用高重要性通知，提供“忽略 / 查看提醒”。具体悬浮样式、声音和送达受系统通知通道、勿扰、省电及厂商策略控制。实现依据：[Android 闹钟文档](https://developer.android.com/develop/background-work/services/alarms)、[通知权限文档](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。

## 隐私与一致性

- 调度/恢复仅读取 ID 和时间；触发时才读取当前笔记，检查是否删除、提醒是否改期，拒绝旧时间的闹钟。
- 隐私笔记或设备启用应用锁时，只发送通用提示；锁屏使用不含正文的公开通知版本。
- 点击通知先等待应用锁通过。隐私笔记再独立认证，并在受隐私空间保护的嵌套导航中打开编辑器。
- 删除、取消或修改时取消旧闹钟与已显示的对应通知。恢复备份期间暂停通知、取消旧调度，成功或回滚后重新同步。

## 自动化与人工验收

自动化覆盖持久化、v8 升级、元数据与自动保存并发、权限拒绝、过期时间、设置失败回滚、修改/取消、日期文案、窄屏大字布局，以及应用锁/隐私认证后的通知跳转。

真机验收从一分钟后的提醒开始。返回桌面后检查“忽略 / 查看提醒”，再覆盖修改、取消、删除、重启、权限变化、隐私笔记和厂商后台策略。
