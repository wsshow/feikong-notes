# 非空笔记图片分享

从编辑器导出分页 PNG，通过 Android 系统分享面板发送。

## 入口与流程

编辑器右上角“更多 → 分享为图片”打开全屏制作页。入口使用当前编辑会话的标题、Delta 和附件创建快照，不要求用户先手动保存；没有可分享内容时给予提示。

制作页包含分页预览、样式与画幅设置、内容选项，以及底部“生成并分享”。生成期间显示页数进度并防止重复操作，完成后调用系统分享面板。

## 当前选项

- 内置模板由 `NoteShareTemplateId` 定义，当前包含来信、素笺、夜读等 15 套样式。
- 画幅支持 1:1、4:5、3:4、9:16、16:9、A4、长图和自定义尺寸。
- 支持方向、标准/高清/超清以及三档排版密度；长图和自定义尺寸遵循各自限制。
- 可选择显示标题、日期、标签、图片和其他附件。
- 中文来源标识使用“非空笔记”，不提供移除来源的开关。
- 最近配置由 `NoteSharePreferencesService` 保存在本地，配置不可读时回退到默认值。

导出画布使用所选模板的配色与排版。制作页的按钮、工具和导航遵循[应用设计规范](../DESIGN.md)。

## 渲染结构

1. `NoteShareDraft` 从笔记快照生成语义块与样式范围。
2. `NoteShareLayoutEngine` 测量正文、图片和表格，产出分页结果。
3. `NoteSharePageCanvas` 同时用于预览和导出，避免两条排版路径产生差异。
4. 制作页逐页渲染、编码 PNG；`NoteShareImageService` 写入独立临时会话并交给系统分享。

逻辑尺寸与导出像素分开处理，不通过缩小整篇文字强行塞进一页。超长内容需分页，标题、列表、引用、表格、样式范围与附件都要纳入测量。

### 卡片的静态分享形态

- 文件引用保留为独立资料清单，按引用快照显示文件类型、完整名称和大小，不再降级为顿号拼接的正文。长文件名自然换行，多页画幅按文件条目拆分并重复“文件引用（续）”标题；关闭附件选项时一并隐藏引用卡片。
- 音频、视频及普通附件共用紧凑信息卡，保留自定义标题、类型、文件大小，以及已有的音视频时长。名称参与排版测量，不依赖固定高度裁掉长标题。
- 图片保持完整比例；无法读取时在原图位置显示带文件名的说明。关闭图片显示时以信息卡替代。
- 表格保持网格与单元格对齐，跨页重复表头；引用、代码、列表与正文链接保留各自排版。静态导出不带编辑菜单、删除、展开或播放等交互控件。
- 卡片使用所选分享模板的语义配色，预览和 PNG 导出复用同一渲染与测量规则。

自定义画幅下限为 480px，宽度上限为 4096px、高度上限为 12000px，总像素限制为 2000 万；具体边界以 `NoteShareCanvasSpec` 为准。

## 数据边界

- 排版和生成在本地完成，不创建公开 URL，也不自动上传原始笔记。
- 分享文件位于临时目录的 `fknotes_share_exports/<会话 ID>/`，不写入永久附件目录。
- 分享取消或生成失败时尽力删除本次临时会话；成功分享后暂时保留文件供接收应用读取，在后续创建会话时清理超过 24 小时的旧文件。
- 文件名经过清理并附带页码；导出来源信息不应泄露本地路径或数据库 ID。
- 生成失败保留制作配置和原笔记；用户取消系统分享不应当作笔记保存失败。
