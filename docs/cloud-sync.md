# 备份与手动云同步

完整备份使用 `.fknotes.zip`，由用户管理。Android 的系统备份与设备迁移已关闭。云同步复用备份格式，通过用户配置的 HTTPS S3 或 WebDAV 服务交换快照。在设置中配置并点击“立即同步”后才会发起同步。

iOS 备份导入使用 ZIP 类型标识选择文件；另存走系统 Files 导出选择器，成功和取消分别反馈。含隐私内容的归档仍须先通过既有认证。文件入口已适配，跨设备恢复与系统文件提供程序仍待真机验收；这里的手动备份不代表已配置 iOS 系统备份策略。

## 备份范围

| 纳入归档 | 留在本机 |
| --- | --- |
| 笔记数据库、普通和隐私笔记、隐私标记、附件与缩略图 | 模型和下载缓存、推理缓存、转写临时文件、恢复草稿 |
| 文件库索引、文件及回收站 | 应用锁、模型密钥和云同步账号配置 |
| 可迁移设置、普通与隐私对话的只读快照及对话图片 | 任务的执行授权、续跑状态与操作回执 |

归档本身未加密。生成、另存或分享含隐私内容的备份，以及上传这类云同步快照前，均需系统认证。应用先冻结临时快照，再验证该快照的权限，处理完成后清理临时文件。恢复保留隐私标记，对话快照在目标设备重新加密。云同步账号从本机私有目录的 `settings/cloud-sync.json` 读取。

恢复时校验归档路径、逐文件 SHA-256、内容指纹、数据库及文件库结构，校验通过后才替换本机数据。失败会回滚。旧格式及空间隔离见[文件管理器](file-manager.md#备份与验证)与[隐私工作区](private-workspace.md)。

## 同步流程

远端保存 `latest.json` 和 `snapshots/<revision>.fknotes.zip`。上传先写快照，再更新清单，成功后清理旧快照。下载先读清单，再核对归档长度和哈希，随后走完整恢复流程。

| 指纹比较 | 行为 |
| --- | --- |
| 两端相同 | 只更新同步状态 |
| 只有本机变化 | 上传本机快照 |
| 只有云端变化 | 下载并恢复云端快照 |
| 两端均变化，或首次连接时云端已有数据 | 由用户选择保留本机或使用云端 |

## 服务配置

- **WebDAV。** 配置 HTTPS 地址、用户名、密码和远程目录。连接测试使用 `PROPFIND`，并对临时对象执行写入、读取、删除。连接校验 TLS 证书，凭据限于当前服务。
- **S3。** 配置 Endpoint、Region、Bucket、Access Key ID、Secret Access Key、对象前缀及 Path-style。使用 AWS Signature Version 4。同步前缀需要 `s3:GetObject`、`s3:PutObject` 和 `s3:DeleteObject`，连接测试直接读写临时对象。
