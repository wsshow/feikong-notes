# 非空笔记编辑器架构

本文维护文档模型、编辑会话与保存机制。界面规则见[设计规范](../DESIGN.md#编辑器)。

## 文档与编辑会话

- `NoteDocument` 保存经过校验的 Quill Delta，正文只有一个连续的富文本输入、光标、选区与撤销上下文；标题使用独立输入框。
- `NoteEditorController` 持有 `QuillController`、附件索引和内容修订号，处理粘贴、嵌入节点、格式及 AI 插入事务。
- 普通按键不重建整篇语义投影。自动保存、分享等消费者调用 `snapshot()` 时，才进行完整校验与附件引用核对。
- `NoteEmbed` 支持附件、文件引用组、分隔线和表格。正文以稳定 ID 引用附件和资料。批量资料合为一张卡片，插入当前光标处，未聚焦时追加到末尾。文件解析和拖动规则见[文件管理器](file-manager.md#文件引用)。
- 表格编辑使用独立弹层，确认后回写文档节点；不为普通段落或列表创建独立文本输入框。
- Markdown 由 `NoteMarkdownCodec` 在导入、粘贴和输出边界转换，不作为编辑中的事实来源。

## Markdown 导入

- 外部分享的文本和可内联的文本文件先识别 Markdown 语义，标题、引用、列表、代码和表格转为原生 Delta；普通文本保留原有导入方式，文件大小、编码和附件回退限制不变。
- 文档开头由 `---` 包围的 YAML front matter（也接受 `...` 结束符）使用共享解析器转换为可编辑的元数据表格，保留字段值；没有分享标题时用字符串 `title` 填充笔记标题。阅读视图、粘贴和 AI 输出采用相同解析规则。
- 只识别完整、有效且大小受限的顶层 YAML 映射，不把正文分隔线、引用或代码块里的示例当作元数据。元数据单元格按字面值处理，不再次执行 Markdown 内联解析。外部 Markdown 图片保留为链接，不自动下载。
- 已保存的纯文本可通过重新分享或粘贴转换。

## 页面与焦点

- `NoteQuillEditorPage` 负责页面生命周期、标题、标签、自动保存、附件导入与导航。
- 标题下方的信息行集中显示更新时间、正文字符数、提醒与标签。字符数按 Unicode 字素统计，排除标题、空白和附件占位符；按内容版本缓存，不在普通头部重建时生成完整快照。标签通过文字入口或更多菜单编辑，提醒与到期时间保持原有行为。
- `NoteQuillEditor` 渲染正文及附件嵌入节点。图片、音频、视频、普通文件、文件引用、表格和分隔线均占独立块行；块行不绘制文字或浮动光标。编辑折叠选区按键盘方向跳过块行，插入后与输入法输入统一落到正文段落；只有明确进入编辑或输入时才补正文行。跨块全选/复制/删除仍使用原生范围选区，撤销重做与只读展示不自动增加空行。
- 顶部大纲按钮打开 `NoteOutlineSheet`，按当前 Delta 的标题 1–6 构建层级；`NoteOutlineEntry` 保留 UTF-16 偏移，兼容重名标题、混合行内格式和附件。大纲仅在弹窗可见时读取，点击后使用原生编辑器坐标定位，不修改内容、撤销历史或强制打开键盘。
- 更多菜单仅启动朗读；`NoteReadAloudBar` 在格式工具栏上方悬浮显示准备 / 播放状态及停止操作，完成或停止后收起，正文视口避开控件。仍读取最新未保存的文本，保留离线模型检查、错误反馈、隐私后台停止和离开页面停止；停止准备后不会因模型检查迟到而重新启动。
- `NoteQuillToolbar` 是底部单行横向工具栏；“完成”固定在右侧，不随横向滚动离开。
- 正文 / 标题与底部 AI 输入面板直接交接焦点，键盘已打开时保持显示，关闭 AI 返回正文也不经过清空焦点的中间帧。切换处理范围、撤销后继续输入和继续创作使用同样的焦点请求方式；原正文选区与内容保持。
- 标签、链接、附件标题、文件 / 文件夹名称及聊天待发送内容的编辑表单使用 `AppOverlay.inputSheet`，由自动聚焦的输入框接管键盘，弹窗路由不先抢占空焦点作用域。录音、只读选择和生成结果面板保留各自的键盘收起规则。
- 正文与附件始终使用屏幕内的可用宽度。每个代码块独立横向滚动，背景与边框不随长行撑开；只在块内有溢出时显示细滚动条。
- 代码宽度由原生文本布局测量，不按字符数猜测、不设置截断长行的宽度上限。光标、跨段选区和输入法仍属于同一个 Quill 编辑会话。
- Android / iOS 长按按实际文字框选词，继续拖动保留起始词；手柄从绘制端点跟随手指移动，兼容反向选区、自动换行和代码横向滚动。纵向拖选仅在视口上下 40dp 边缘区域渐进滚动，上限 180dp/s，移回正文或结束手势即停止；拖选期间暂停光标自动滚动，避免跨行跳动。回归测试见 `note_editor_selection_test.dart`，速度值是当前交互参数，不代表系统平台常量。
- 长按、拖选、全选和复制只获取选区操作所需的焦点，输入连接可建立但不请求弹出软键盘。键盘已打开时保留，手动收起后选区变化不再次唤起；单击正文、新建笔记自动聚焦、标题提交进入正文等明确编辑操作正常弹出。测试使用平台键盘可见性处理入口模拟收起，直接检查 `TextInput.show` 调用，不依赖上游默认的“测试键盘始终可见”假设。
## 格式与排版

- 工具栏通过 `AppIcon` 接入 Quill 回调，保留撤销、禁用、选中和无障碍状态。
- 列表层级存于 Delta 换行符的 `list` 和 `indent`。编辑最多增加到 5 级，导入的更深层级可逐级减少。多行缩进作用于选中行，子待办完成状态独立。
- 编辑与预览共用正文排版与首行列表标记对齐逻辑。默认样式只参与渲染，尺寸见[长文排版规范](../DESIGN.md#笔记长文排版)。

当前依赖固定为 Flutter Quill 11.5.1，运行时与代码块视口兼容补丁收录于 [third_party/flutter_quill](../third_party/flutter_quill/README.md)。包来源、许可、修改范围及升级流程均记录在该目录。其剪贴板扩展、工具栏 builder、代码块滚动与选区坐标由编辑器测试覆盖；升级依赖时需重点回归这些入口。

## 保存与数据安全

- 页面默认使用约 700ms 的自动保存防抖，写入通过串行队列执行。
- `NoteEditorWriter` 将有效快照交给仓库；仓库以笔记 `revision` 检测并发写入冲突。
- 正常退出前等待最新有效内容保存。失败时保留页面内容，提示重试或由用户明确决定后续操作。
- 附件导入保留进度与失败状态，未完成的导入不能伪装成可用附件。
- 删除是永久删除，必须明确确认；分享和预览不能改写原始笔记。
- 数据库升级由 `NoteRepository.upgrade` 管理。旧界面退场不意味着可以删除历史数据表、回退 schema 版本或移除兼容测试。
- schema v8 在 `notes` 增加 `is_private`（默认 0）。旧笔记升级后仍为普通笔记，隐私草稿与后续编辑保留该标记；`get/list/search` 默认只读普通空间，隐私读者必须显式传入 `privateSpace: true`。
- 隐私编辑器挂在独立认证页的嵌套 Navigator 内，后台遮挡覆盖整个路由栈而不销毁未完成的草稿。数据库和附件仍使用原有应用私有目录，不宣称文件加密；完整备份保留隐私标记并在生成、导出前认证。

## AI 与语音

- AI 插入捕获原始 Delta、选区与目标位置，流式写入必须遵守当前插入会话的边界。
- 生成结束后的撤销应恢复原文，不能要求用户逐段撤销流式输出。
- 听写、附件识别和朗读仍由各自的本地服务管理，模型缺失、加载、取消和失败必须有可理解的状态。
- 聊天中的笔记创建、追加和替换按任务授权与所选审批模式执行。详见[智能体使用与维护](fknotes-harness.md#执行约定)。

## 录音转写

- 语音卡片右侧操作按钮无需先选中卡片，第一次点击即可打开菜单；修改标题和移除保留，新增“语音识别”。选中边框始终使用同一层级，不在按下和抬起之间重新挂载按钮。
- 复用 `SpeechTranscriptionService` 的 SenseVoice 离线模型、音频解码和后台识别任务。首次进入无转写的录音时开始识别，已有结果直接展示；模型未安装时提供模型管理入口，不擅自下载模型。
- 底部弹窗展示真实处理阶段、进度和转写文字，可复制、取消或重新识别。关闭弹窗或离开笔记不取消后台任务；保存阶段不可取消，避免已写入结果却显示“已取消”。
- 转写写入附件的 `transcript`、`transcriptionEngine` 和 `transcribedAt`，不修改正文或原音频。任务启动前先保存草稿；编辑器打开时通过同一个保存队列合并结果，关闭后从仓库读取最新修订后写入，防止覆盖用户正在输入的正文与标题。
- 写入核对笔记空间、附件引用与音频存储键；移除或替换后的旧结果不写回。隐私转写保留空间隔离，结果弹窗沿用受保护的 Navigator。识别失败或保存失败不覆盖旧转写，失败状态不等同于保存完成。
- 自动化覆盖见 `note_audio_transcription_test.dart`、`note_quill_editor_test.dart` 与 `speech_transcription_service_test.dart`。模型推理速度、实际识别质量和界面仍需设备验收。

## 图片 OCR

- 点击正文图片后，浮动工具栏依次提供查看原图、复制、操作、详情、删除。“操作”底部菜单保留修改标题、从相册替换、重新拍摄，并加入“OCR 识别文字”。
- OCR 复用随应用提供的 ML Kit 中文识别器，读取托管原图，不上传图片、不额外下载模型。进入结果弹窗时，已有识别文字直接显示；没有结果时开始识别，可选择文字、复制全部或重新识别。复制只能由用户主动触发。
- 结果写入附件已有的 `ocrText` 字段，通过编辑器保存队列持久化；参与笔记搜索和已有附件上下文，不插入或改写正文。替换图片不继承旧图片的 OCR 结果。
- 识别中、没有文字和识别失败分别展示；失败或空结果不覆盖之前保存的文字。保存失败时弹窗保留新结果供复制或重试，附件恢复原有 OCR 文字，重试保存不再次运行识别。
- 关闭弹窗后忽略尚未返回的识别结果。写回前核对附件引用和原图存储键，避免写入已删除或已替换的图片；共用原生识别器串行处理请求。隐私笔记沿用受保护的嵌套 Navigator，不把识别结果带到外层页面。
- 结果区域可独立滚动，整个弹窗也可滚动，按钮在窄屏和大字号下自动换行。自动化覆盖见 `note_image_ocr_test.dart`、`ocr_service_test.dart` 与仓库测试；实际图片的识别质量由设备验收确认。
