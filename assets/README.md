# 素材来源与许可

以下视觉素材由 FKNotes 项目自行创作，随项目采用根目录的 [MIT License](../LICENSE)：

| 素材 | 内容 |
| --- | --- |
| `brand/` | 小象便签 Logo 母版、应用图标和品牌标志 |
| `textures/editorial_paper.png` | 纸张主题纹理 |
| `themes/sunny_growth/` | Sunny Growth 主题矢量图形与设计参数 |

由这些源文件生成的各平台启动器图标、启动页图片和主题代码沿用同一许可。
品牌素材的生成方式见[品牌说明](brand/README.md)。

第三方素材单独保留原有许可：

- `fonts/source_han_serif/` 中的思源宋体来自 Adobe，采用 SIL Open Font License 1.1，
  版本、来源和校验值见[字体说明](fonts/source_han_serif/README.md)。
- 应用操作图标中的 Lucide / Feather 路径采用上游 ISC / MIT 许可，
  来源和项目自定义图标的边界见[图标说明](../third_party/lucide/README.md)。

本项目的 MIT 许可不替代上述第三方许可，也不替代外部 SDK 和模型的适用条款。
