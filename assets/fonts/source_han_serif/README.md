# Source Han Serif CN

This directory contains the Simplified Chinese subset variable OTF from
Adobe's Source Han Serif 2.003R release.

- Source: https://github.com/adobe-fonts/source-han-serif
- File: `Variable/OTF/Subset/SourceHanSerifCN-VF.otf`
- SHA-256: `0926369670e4b18b63ae2642ac5b57c2e03343c2f3083c4ec98e8c0117edea4f`
- License: SIL Open Font License 1.1; see `LICENSE.txt`.

The single variable font provides the complete weight range used by the
editorial theme while avoiding duplicate glyph data across static weights.
